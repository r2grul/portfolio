# Uygulama Rehberleri

Bir kabin üreticisinin sipariş, satın alma, lazer kesim, maliyet, teslim ve etiket süreçleri için geliştirdiğim beş masaüstü uygulamasının (C# / .NET WPF / SQL Server) ekran görüntülü kullanım rehberleri.

### 👉 [Rehberleri web sayfası olarak aç](https://r2grul.github.io/uygulama-rehberleri/)

| Uygulama | Ne işe yarar? |
|---|---|
| [BK Sipariş](https://r2grul.github.io/uygulama-rehberleri/bk-siparis/) | Yapay zekâ destekli sipariş yönetimi, sac/cam sipariş, satın alma, teklif, irsaliye ve stok |
| [Lazer Kesim](https://r2grul.github.io/uygulama-rehberleri/lazer-kesim/) | Nesting planlarını kesime hazırlama, Metalix uyumlu CSV, kesim takibi, stoktan otomatik düşüm |
| [Kesim Maliyet](https://r2grul.github.io/uygulama-rehberleri/kesim-maliyet/) | Parametrik maliyet hesabı, müşteriye özel fiyat, PDF teklif |
| [Teslim Kontrol](https://r2grul.github.io/uygulama-rehberleri/teslim-kontrol/) | Satın alma talebi, sac/cam/çerçeve teslim ve kalite kontrol, irsaliye işleme |
| [BK-ETK](https://r2grul.github.io/uygulama-rehberleri/bk-etk/) | Şablonlarla etiket tasarımı ve basımı |

Bütün ekran görüntüleri uygulamaların demo modunda, ayrı bir demo veritabanından alınmıştır. Veriler gerçek değildir; firma adı ve logosu gizlenmiştir. Uygulamaların kaynak kodu firmaya ait olduğu için paylaşılmamaktadır.
