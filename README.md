# Uygulama Rehberleri

Bir kabin üreticisinin sipariş, satın alma, lazer kesim, maliyet, teslim ve etiket süreçleri için geliştirdiğim beş masaüstü uygulamasının (C# / .NET WPF / SQL Server) ekran görüntülü kullanım rehberleri.

**Site:** bu deponun GitHub Pages sayfası (ana sayfa `index.html`).

| Uygulama | Ne işe yarar? |
|---|---|
| [BK Sipariş](bk-siparis/) | Yapay zekâ destekli sipariş yönetimi, sac/cam sipariş, satın alma, teklif, irsaliye ve stok |
| [Lazer Kesim](lazer-kesim/) | Nesting planlarını kesime hazırlama, Metalix uyumlu CSV, kesim takibi, stoktan otomatik düşüm |
| [Kesim Maliyet](kesim-maliyet/) | Parametrik maliyet hesabı, müşteriye özel fiyat, PDF teklif |
| [Teslim Kontrol](teslim-kontrol/) | Satın alma talebi, sac/cam/çerçeve teslim ve kalite kontrol, irsaliye işleme |
| [BK-ETK](bk-etk/) | Şablonlarla etiket tasarımı ve basımı |

Bütün ekran görüntüleri uygulamaların demo modunda, ayrı bir demo veritabanından alınmıştır. Veriler gerçek değildir; firma adı ve logosu gizlenmiştir. Uygulamaların kaynak kodu firmaya ait olduğu için paylaşılmamaktadır.
